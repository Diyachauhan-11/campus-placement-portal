# CampusBridge — Unified Academic & Student Services Portal

CampusBridge is a full-stack student web platform designed to bring campus academic resources, student authentication, and university services under a single modern dashboard.

## What Problem Does It Solve?

College students typically have to navigate multiple fragmented portals for course updates, internal tools, and academic profiles. CampusBridge unifies these services with a clean, centralized interface, secure user authentication, and real-time backend synchronization.


## Key Features

- **Student Authentication & Access Control:** Secure account login and session management for students.
- **Unified Academic Dashboard:** Clean dark-mode interface displaying student credentials, active courses, and key campus shortcuts.
- **RESTful API Architecture:** Decoupled client-server design ensuring fast data retrieval and independent deployment.
- **Cloud-Ready & Fully Deployed:** Production deployment with frontend hosted on Vercel and backend micro-services running on Render.
- **Mobile Responsive:** Designed with Tailwind CSS for seamless access across mobile screens and desktops.


## Tech Stack

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Backend:** Node.js, Express.js (REST API, CORS)
- **Deployment:** Vercel (Frontend), Render (API)
